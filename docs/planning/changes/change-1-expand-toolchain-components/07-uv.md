# Question

Part of "what else is missing". The JS side of this box is well served —
`node`, `bun`, `pnpm`, three package managers. The Python side has `python` +
`ensurepip`-bootstrapped `pip` and nothing else.

`install_python` (`vps-boot.sh:601-632`) deliberately does not repoint
`/usr/bin/python3`, exposing the deadsnakes interpreter only as `python` via
`update-alternatives`. That is the right call for the system's sake, but it
leaves an environment where `pip install` into the system interpreter is the
path of least resistance and the wrong thing to do. `uv` is the standard answer:
it resolves, installs and manages per-project environments, and can fetch its
own interpreters.

**`uv` is already on the box — but privately.** Hermes' installer downloads its
own `uv` to `~/.hermes/bin/uv` and uses it to manage a private Python 3.11 and a
private Node under `~/.hermes/`. None of that is on `PATH`, none of it is
usable for the operator's own projects, and all of it disappears if Hermes is
unticked. So it does not answer this decision — but it is worth knowing that the
tool is already trusted enough to be vendored by a component that ships today.

Install shape: `curl -LsSf https://astral.sh/uv/install.sh | sh`, with
`UV_INSTALL_DIR` overriding the default `~/.local/bin`. That is exactly the
`install_herdr` situation (`vps-boot.sh:714-719`) — an upstream default that is
not on `PATH` for a fresh root-only box, fixed by pinning the install dir to
`/usr/local/bin`. So there is a proven precedent in the file to copy verbatim.

# Options

- **A. `uv` component, `UV_INSTALL_DIR=/usr/local/bin`** — mirrors `install_herdr`,
  system-wide, no `PATH` edit needed.
- **B. Install `uv` via `pip install uv` into the deadsnakes interpreter** —
  couples `uv` to the component whose weakness it exists to cover, and puts it
  behind `python` in the registry.
- **C. Skip** — `pip` is there.

# Recommendation

**A.** It closes the most conspicuous asymmetry in the current registry — three
JS package managers to zero modern Python ones — for one line of install code
following a pattern already in the file. Register after `python` so the ordering
reads sensibly, though `uv` has no actual dependency on it.

# Verdict

**A.** Accepted at triage.

`curl -LsSf https://astral.sh/uv/install.sh | UV_INSTALL_DIR=/usr/local/bin sh`,
mirroring `install_herdr`'s pinned-install-dir fix. `system` scope, `packaging`
group with `bun` and `pnpm`. Hermes' private `~/.hermes/bin/uv` does not answer
this need — it is not on `PATH` and vanishes with the component.
