# vps-boot — Epics

Trackable units of work, each with a GitHub milestone and a tracking issue.
Epics produced from the brownfield pipeline carry a `source` pointing at the
change ledger under `../planning/changes/` that decided them. Epic 0 is the
remediation lane — repairs a review turned up that the project cannot proceed
past — and its `source` points at the reports it consumed.
